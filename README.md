# MOTORVAULT

A static vehicle marketplace demo built with HTML, CSS, and vanilla JavaScript. Open `index.html` directly or serve the folder with VS Code Live Server.

## Demo flows

- Browse, search, sort, and filter the local sample inventory.
- Save favorites and compare up to four vehicles.
- View vehicle details, switch gallery images, and estimate financing.
- Add unique vehicle listings to a reservation cart and complete a simulated checkout.

All listing data is fictional sample content. Checkout and forms are simulated in the browser; no payment or message is sent to a server. Vehicle photos load from Unsplash and require an internet connection.
